SMS Opt-In

How users agree to receive verification codes by text message

Daila Hub sends one-time verification codes by text message, only when a user asks to sign in with their mobile number. No marketing messages are sent. The Daila Hub app is not yet publicly available, so the screenshots below show the sign-in flow where consent is given.

1. The sign-in form

When a user enters a mobile number on the sign-in page, this disclosure appears below the field before any message is sent:

By continuing, you agree to receive one-time verification codes by text message from Daila Hub at this number. Message and data rates may apply. Message frequency varies by account activity. Reply STOP to opt out — this will disable SMS sign-in. Reply HELP for help.

The user selects Continue to agree and request a code. The same disclosure is shown when a user adds a phone number in account settings.

2. After the form is submitted

After the user selects Continue, a one-time code is sent and the user is asked to enter it.

Sample message

Your Daila Hub verification code is: 123456. Valid for 5 minutes. Do not share this code.

Consent records and opting out

  • Each consent is recorded with the time, the version of the disclosure shown, the user's IP address and browser type.
  • Reply STOP to opt out, START to opt back in, or HELP for help. Help is also available at support@dailahub.com.
  • Program terms: SMS verification program. Mobile numbers are never shared for marketing: Privacy Policy.
